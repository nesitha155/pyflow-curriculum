Lists & Tuples

Learn how to store multiple items inside a single variable using square brackets [] and parentheses ().

Changeable Collections

🛍️ Python Lists (Like a Shopping Bag)

Instead of creating 10 separate variables for 10 items, you can put them all in one List using square brackets []. Just like a shopping bag, you can add new items, remove items, or swap them anytime!

# Create a list of snacks
snacks = ["Chips", "Cookies", "Juice"]

# Add a new item to the end
snacks.append("Apple")
print(snacks)
Finding Items

🔢 Counting Starts at Zero (Indexing)

Every item in a list has a position number called an index. In Python, counting always starts at 0—so the very first item is at index [0]!

colors = ["Red", "Green", "Blue"]

print(colors[0]) # Prints "Red" (1st item)
print(colors[2]) # Prints "Blue" (3rd item)
print(colors[-1]) # Prints "Blue" (Last item!)
Locked Collections

🔒 Python Tuples (Locked Time Capsules)

A Tuple looks just like a list, except it uses round parentheses (). Once you create a tuple, it is locked—you cannot add, remove, or change any items inside it. Use tuples for data that should never change, like GPS coordinates or birthdates!

# Coordinates locked inside a tuple
spawn_point = (100, 250)

print(spawn_point[0]) # Prints 100
# spawn_point[0] = 500 --> Error! Tuples cannot be changed.
