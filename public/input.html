Neural Input & Type Conversions

Learn how to capture user input streams and convert data types for system processing.

📥 Capturing User Data with input()

So far, our programs have been one-way streets (we write the data, the computer prints it). To make programs interactive, we use Python's built-in input() function. This pauses the program, prints a prompt to the user, and waits for them to type an answer.

user_interface.py ● Interactive Stream
# Pause program and wait for user input
pilot_name = input("Enter pilot designation: ")

print("Welcome back, " + pilot_name)

⚠️ The Golden Rule: input() Always Returns a String

Even if the user types a pure number like 50 into the prompt, Python automatically wraps it in quotation marks and stores it as a text string (str).

1
The Danger of String Math

If you ask a user for their age using age = input("Enter age: ") and type 20, Python stores it as "20". If you try to calculate age + 5, Python crashes with a TypeError because you can't add text and numbers together!

2
The Solution: Type Casting (`int()` & `float()`)

To convert text numbers into actual math numbers, we wrap the input function in a casting function like int() or float().

casting_pipeline.py ▶ Run Conversion
# Convert input string into an integer
battery = int(input("Enter battery %: "))

# Now math operations work safely!
remaining = battery - 15
print(remaining)
> User entered: "100" (Cast from str -> int)
