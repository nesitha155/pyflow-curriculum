What is a Web API?

Understand how software applications talk to each other across the internet using requests and responses.

The Waiter Analogy

🍽️ How APIs Work in Real Life

Imagine sitting at a restaurant table. You (the client application) look at the menu and decide what you want. But you can't walk back into the kitchen (the server and database) to cook it yourself. So, you give your order to a Waiter. The waiter takes your request to the kitchen, gets your food, and brings it back to your table.

An API (Application Programming Interface) is that digital waiter. It takes requests from your browser or app, asks the server for data, and delivers the response back safely.

Data Format

📦 JSON: The Universal Language of the Web

When web APIs talk to each other, they usually exchange data in a format called JSON (JavaScript Object Notation). It looks almost identical to Python dictionaries!

// Example of a JSON response from a robot API
{
    "robot_id": "RX-90",
    "status": "online",
    "battery_level": 92
}
