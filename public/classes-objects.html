Level 4 • Topic 01

Classes & Objects

Learn the foundation of Object-Oriented Programming by exploring blueprints and real-world instances.

Blueprints

📐 What is a Class? (The Blueprint)

Imagine an architect drawing a blueprint for a house. You cannot live inside the blueprint itself, but you can use it to build 100 identical houses. In Python, a class is that architectural blueprint. You use the class keyword to create it.

class Robot:
    # This is the blueprint for all robots
    pass
Instances

🤖 What is an Object? (The Real Thing)

An object is a real working instance created from your class blueprint. When you build an object from a class, we call it instantiation. You can create as many unique robot objects as you want!

class Robot:
    pass

# Create two real robot objects from the blueprint
robot_one = Robot()
robot_two = Robot()

print(robot_one) # Output shows the object instance
