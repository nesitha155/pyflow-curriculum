FastAPI Basics

Spin up your very first asynchronous web server using Python, Uvicorn, and basic routing endpoints.

Server Setup

🚀 Spawning Your First Server

FastAPI is a modern, high-performance web framework for building APIs with Python. To run it locally, you install FastAPI and an ASGI server called Uvicorn in your terminal:

pip install fastapi uvicorn

Next, create a file named main.py and write your very first API endpoint:

from fastapi import FastAPI

# Initialize the FastAPI app
app = FastAPI()

# Create a route for the home page URL ("/")
@app.get("/")
def home_page():
    return {"message": "Welcome to the PyFlow Robot API!"}
Execution

⚡ Running Your Server with Uvicorn

To boot up your backend server, run this command in your terminal. The --reload flag automatically restarts your server whenever you save code changes:

uvicorn main:app --reload

Once running, opening http://127.0.0.1:8000 in your browser will instantly display your JSON response! FastAPI even generates interactive documentation automatically at /docs.
