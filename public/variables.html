Variables & Memory Cells

Store, change, and name data values safely inside Python memory.

📦 The Storage Box Concept

Think of a variable like a labeled cardboard storage box. You write a name on the outside (the variable name), and put an item inside (the value) using the = assignment operator.

[ Box Label ]
player_score
[ Stored Value ]
50

🔄 Changing Variables (Reassignment)

Variables are mutable—meaning their values can change while your program runs. When you assign a new value to an existing variable name, Python replaces the old value instantly.

# 1. Initial assignment
score = 50
# 2. Reassignment (updating value)
score = score + 10 # Now score is 60!

🏷️ Variable Naming Rules & Best Practices

Python is strict about how you name your variables. If you break these rules, Python will throw a SyntaxError before your program even starts.

Rule Category ✅ Valid Example ❌ Invalid Example (Error)
Cannot start with a number robot_1 = "Atlas" 1_robot = "Atlas" (Starts with digit)
No spaces allowed battery_level = 100 battery level = 100 (Has a space)
Case Sensitive Score = 10 and score = 20 are two separate variables! N/A (Just watch out for uppercase mistakes)
No special symbols user_age = 25 user-age = 25 or user$ = 25

💡 Pro Tip (snake_case): Always name multi-word variables using lowercase letters separated by underscores, like total_score or player_health_status. Avoid using Python's built-in keywords (like print, if, or for) as variable names!
