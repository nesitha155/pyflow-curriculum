Connect your Python program to generative AI models and build automated intelligent assistants.

AI Integration

⚡ Talking to AI from Python

Building an AI script is simpler than you think! Just like we connected to web servers in Level 5, your Python script can send text prompts to an AI model's API and instantly receive generated answers back.

import openai

# Send a prompt to the AI model
response = openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Write a greeting for my robot."}]
)

print(response.choices[0].message.content)
