Python Functions

Learn how to write code once and reuse it whenever you want using def.

The Basics

🎂 What is a Function?

Imagine you have a favorite recipe. Instead of writing out all the steps every single time you want to bake a cake, you write it down once on a card and call it "Bake Cake".

In Python, a function is just a mini-program or a reusable block of code. You use the keyword def (short for "define") to create it.

def say_hello():
    print("Hello, welcome to PyFlow!")

# Now, call your function to run it:
say_hello()
Inputs

📥 Giving Information to Functions (Parameters)

Sometimes your function needs extra details to do its job. You can pass parameters (inputs) inside the parentheses. Think of it like telling a vending machine which snack button to press.

def greet_user(name):
    print(f"Hello, {name}!")

# Pass different names into the function
greet_user("Alex")
greet_user("Sarah")
Outputs

📤 Getting Answers Back (return)

Printing text on the screen is nice, but what if you want your function to do math and give you an answer you can save in a variable? Use the return keyword.

def add_numbers(a, b):
    return a + b

# Save the returned result into a variable
total = add_numbers(5, 3)
print(total) # Output will be 8
