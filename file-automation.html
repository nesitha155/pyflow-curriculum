Automating Boring Files

Learn how to write Python scripts that instantly scan folders, organize messy files, and handle bulk operations.

File Systems

📂 Scanning Folders with Python

Python's built-in os module lets your script look inside any folder on your computer. You can list every file name, check file sizes, and find specific file extensions automatically.

import os

# List all files and folders in the current directory
files = os.listdir(".")
for file in files:
    print(f"Found item: {file}")
Bulk Operations

📦 Moving & Sorting Files

To move files safely, we ensure the destination folder exists using os.makedirs() first. Then, our loop checks each file extension and relocates it instantly with shutil.move().

import os
import shutil

# Create target folder if it doesn't exist yet
os.makedirs("images", exist_ok=True)

# Loop through files and sort .png images
for file in os.listdir("."):
    if file.endswith(".png"):
        shutil.move(file, os.path.join("images", file))
        print(f"Moved {file} to images folder.")
