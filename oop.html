Object-Oriented Programming (OOP)

Learn how to bundle data and behavior together using classes and objects.

🏭 What is OOP? (The Robot Factory Analogy)

Up until now, you've written code line-by-line (procedural style). But as programs grow larger, keeping track of hundreds of variables becomes messy. Object-Oriented Programming (OOP) solves this by letting you group related data and actions into custom bundles.

💡 Think of it like a robot factory:
• A Class is the master architectural design drawing (it doesn't do anything by itself yet).
• An Object is a physical robot built from that drawing. You can build 10 different physical robots from that single drawing!

📐 Building a Class & The __init__ Constructor

To create a class in Python, you use the class keyword followed by a Capitalized name. Inside, we write a special setup function called __init__ (short for initialize). Whenever a new robot is born, Python automatically runs this function to set its starting traits (attributes).

robot_factory.py ▶ Run Factory Code
# 1. Define the class blueprint
class Robot:
  def __init__(self, name, model):
    self.name = name      # Attribute
    self.model = model    # Attribute

# 2. Build (instantiate) two physical objects
bot_1 = Robot("Atlas", "X-9")
bot_2 = Robot("Orion", "V-2")

print(bot_1.name)  # Output: Atlas
> Executing factory assembly...
Atlas

⚙️ What on earth is self?

When beginners see self as the first parameter in class functions, it looks confusing. But it's actually very simple:

self simply means "this specific individual robot". If you build bot_1 and bot_2, self ensures that when bot_1 checks its battery, it doesn't accidentally check bot_2's battery! Python passes self behind the scenes automatically whenever you call a method.
