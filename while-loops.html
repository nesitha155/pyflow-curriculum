While Loops & Sentinels

Execute repeating code blocks dynamically until a specific target condition is met.

🔄 Automated Iteration with while

While an if statement checks a condition once, a while loop keeps repeating a block of code over and over again as long as its condition remains True. It acts like a robotic guardian checking a sensor on every cycle.

shield_generator.py ● Loop Monitor
shields = 3

while shields > 0:
  print(f"Shields active. Power remaining: {shields}")
  shields -= 1  # Decrement counter

print("Warning! Shields collapsed!")
⚠️ The Infinite Loop Trap

If you forget to update your counter (like omitting shields -= 1), the condition will never become False. Your program will loop forever, freezing your terminal! Always ensure your loop has a clear exit pathway.

🛡️ Sentinel Values & Interactive Simulation

A sentinel value is a special input or signal used to break a loop (for example, typing "exit" to close a chat bot). Run the simulation below to watch a while loop execute step-by-step:

sentinel_stream.py ● Execution Console
command = ""
while command != "exit":
  command = input("Enter command: ")
> Iteration 1: User typed "status" -> Loop continues.
> Iteration 2: User typed "diagnostics" -> Loop continues.
> Iteration 3: User typed "exit" (Sentinel Value) -> Loop terminated successfully!
