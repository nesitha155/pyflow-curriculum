f-Strings & String Formatting

Inject variables and expressions directly into text streams effortlessly.

✨ What is an f-String?

Often when coding, you need to combine text with variables (like printing "Welcome back, Atlas! Score: 100"). Before Python 3.6, developers had to use messy plus signs and manually cast numbers to text strings. f-strings (Formatted String Literals) make this clean, fast, and readable.

❌ The Old Concatenation Way

Requires manual spaces, plus signs, and str() conversions:

name = "Atlas"
score = 100
print("Pilot " + name + " has score " + str(score))
✅ The Modern f-String Way

Prefix with f and wrap variables in curly braces {}:

name = "Atlas"
score = 100
print(f"Pilot {name} has score {score}")

⚡ Executing Expressions Inside f-Strings

f-strings aren't just for variables—you can write actual Python math or method calls directly inside the curly braces {}!

formatter_console.py ▶ Run f-String Protocol
# Evaluating math expressions directly inside {}
units = 4
power_cells = 50

print(f"Total power capacity: {units * power_cells} kWh")

Total power capacity: 200 kWh
