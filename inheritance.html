Passing Down Features

🧬 What is Inheritance? (Parent & Child Classes)

Instead of writing duplicate code for similar objects, Inheritance lets a new class (the child) inherit all attributes and methods from an existing class (the parent). Think of a FlyingRobot inheriting everything a standard Robot can do, plus brand new flight abilities!

# Parent Class
class Robot:
    def __init__(self, name):
        self.name = name

    def charge(self):
        print(f"{self.name} is recharging battery...")

# Child Class inherits from Robot
class FlyingRobot(Robot):
    def fly(self):
        print(f"{self.name} is taking off into the sky!")

# Create child object and use both parent and child methods
drone = FlyingRobot("SkyBot")
drone.charge() # Inherited from Robot!
drone.fly() # Unique to FlyingRobot!
