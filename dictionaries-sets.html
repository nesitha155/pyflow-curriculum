Dictionaries & Sets

Master labeled key-value data structures and unique filtering collections using curly braces {}.

Key-Value Pairs

📖 Python Dictionaries (Like a Contact Book)

In a list, items are looked up by number index (`0`, `1`, `2`). In a Dictionary, items are stored as key-value pairs using curly braces {}. Think of looking up a friend's name (the key) to find their phone number (the value).

# Robot status dictionary
robot = {
    "name": "PyBot",
    "battery": 85,
    "active": True
}

# Access value using its key
print(robot["name"]) # Outputs "PyBot"
Unique Items

⭐ Python Sets (VIP Guest List - No Duplicates)

A Set also uses curly braces {}, but it only holds unique items. If you try to add the exact same item twice, Python automatically deletes the duplicate! It's perfect for tracking unique tags or visitor IDs.

# Notice duplicate "Python" will be removed automatically
skills = {"Python", "HTML", "CSS", "Python"}

print(skills) # Output: {'Python', 'HTML', 'CSS'}
